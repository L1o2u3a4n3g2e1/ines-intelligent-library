ENDPOINTS THAT WILL BE CREATED

FastAPI Service (Port 8000):
  POST /stt
    Input: audio file, language (rw|en)
    Output: {"language": "rw", "text": "..."}

  POST /translate
    Input: text, direction (rw-en|en-rw)
    Output: {"direction": "rw-en", "input": "...", "translation": "..."}

  POST /tts-rw
    Input: text
    Output: {"audio_file": "outputs/[filename].wav"}

  POST /pipeline
    Input: audio, source_language, target_language
    Output: {"recognized_text": "...", "translated_text": "..."}

  GET /health
    Output: {"status": "ready"}

Node.js Proxy Routes (Port 3001):
  POST /api/audio/stt      → FastAPI /stt
  POST /api/translate      → FastAPI /translate
  POST /api/audio/tts      → FastAPI /tts-rw
